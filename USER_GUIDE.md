## 🎯 О системе

### Назначение

**Система управления персоналом** — веб-приложение для автоматизации кадрового учёта
на промышленном предприятии. Система централизует данные о работниках, ведёт учёт
рабочего времени, рассчитывает заработную плату по нескольким системам оплаты и
предоставляет аналитику через дашборд.

### Основные возможности

- ✅ Полное управление базой работников (CRUD): добавление, просмотр, редактирование, удаление
- ✅ Учёт рабочего времени: плановые и фактические часы, больничные, командировки
- ✅ Расчёт заработной платы: оклад, почасовая, сдельная, проектная системы
- ✅ Справочники: цеха, разряды, категории, режимы работы, системы оплаты, оклады, ставки
- ✅ Поиск работников по ФИО и цеху
- ✅ Дашборд с аналитикой и топами
- ✅ Экспорт данных: PDF-отчёты, CSV, Excel, XML для 1С
- ✅ Мульти-тенантность: поддержка нескольких организаций
- ✅ Ролевая модель: 4 глобальные роли и 4 роли организации
- ✅ REST API с версионированием и Swagger-документацией

## 🚀 Начало работы

### Требования

| Компонент | Версия |
|-----------|--------|
| Java | 17+ |
| Leiningen | 2.x |
| SQLite | 3.x (по умолчанию) или PostgreSQL 12+ |
| Docker (опционально) | 20+ |

### Установка и запуск

```bash
# 1. Клонирование репозитория
git clone git@github.com:alexandervashurin/my-ring-app.git
cd my-ring-app

# 2. Запуск в режиме разработки
lein run

# 3. Сборка и запуск продакшен-JAR
lein uberjar
java -jar target/uberjar/my-ring-app-0.1.0-SNAPSHOT-standalone.jar
```

В режиме продакшена (`ENV=production`) обязательны переменные окружения
`SESSION_SECRET` (ровно 16 байт) и пароль администратора из `.env`.

### Доступ к приложению

После запуска приложение доступно по адресу **http://localhost:3000**.

| Адрес | Назначение |
|-------|------------|
| `/` | Главная страница |
| `/login` | Вход в систему |
| `/dashboard` | Дашборд с аналитикой |
| `/api/health` | Health Check |
| `/api-docs` | Swagger-документация API |

## 🔐 Вход в систему и роли

### Вход и выход

1. Откройте страницу `/login`.
2. Введите **имя пользователя** и **пароль** (выдаются администратором).
3. Нажмите **«Войти»**.

Для выхода нажмите кнопку **«Выйти»** в шапке. Сессия завершается на сервере,
пароль хранится в защищённом виде (bcrypt).

После нескольких неудачных попыток входа система блокирует IP-адрес
(brute-force protection) на ограниченное время.

### Глобальные роли

| Роль | Права |
|------|-------|
| **Администратор** (`admin`) | Полный доступ: всё, что ниже, плюс организации, тарифы, аудит, все таблицы БД, удаление работников |
| **Менеджер** (`manager`) | CRUD работников, зарплата, учёт времени, справочники |
| **HR** (`hr`) | CRUD работников, учёт времени, без доступа к зарплате |
| **Наблюдатель** (`viewer`) | Только просмотр данных |

### Роли организации

В рамках мульти-тенантности пользователь может иметь дополнительную роль внутри
организации:

| Роль | Права |
|------|-------|
| **Администратор организации** (`org_admin`) | Полный доступ в пределах организации, управление пользователями |
| **Менеджер организации** (`org_manager`) | Управление работниками, зарплатой, учётом времени |
| **HR организации** (`org_hr`) | Управление работниками, без зарплаты |
| **Наблюдатель организации** (`org_viewer`) | Только просмотр |

Глобальный `admin` имеет полные права во всех организациях.

### Профиль и смена пароля

1. В шапке нажмите **«Профиль»**.
2. В разделе «Смена пароля» укажите текущий и новый пароль (не менее 6 символов).
3. Сохраните изменения.

## 👥 Работники

### Список работников и поиск

Раздел **«Работники»** (меню → Работники) показывает таблицу всех работников
с расширенной информацией: ФИО, дата приёма, цех, система оплаты, категория,
разряд, режим работы.

- **Поиск** — введите фамилию, имя, отчество или цех в поле поиска. Результаты
  обновляются мгновенно.
- **Учёт времени** — кнопка ⏰ открывает страницу учёта рабочего времени работника.
- **Зарплата** — кнопка 💰 открывает страницу зарплаты работника.

### Добавление работника

1. Нажмите кнопку **«Добавить работника»** на странице списка.
2. Заполните форму:
   - **ФИО** — фамилия и имя обязательны, отчество по желанию;
   - **Дата приёма** — формат ГГГГ-ММ-ДД;
   - **Цех, система оплаты, категория, разряд, режим** — выбираются из
     выпадающих списков справочников;
   - **Оклад (руб/мес)** или **ставка (руб/час)** — поле автоматически
     переключается в зависимости от выбранной системы оплаты.
3. Нажмите **«Сохранить»**. Система выполнит серверную валидацию; при ошибках
   они будут показаны над формой.

### Редактирование и удаление

- **Редактирование** — кнопка ✏️ в таблице; форма заполнена текущими значениями.
- **Удаление** — кнопка 🗑️ (только для администраторов); система запросит
  подтверждение.

### Карточка работника

На странице работника доступны вкладки:

- **Зарплата** — текущее начисление и история по месяцам;
- **Учёт времени** — плановые/фактические часы, дни, больничные, командировки.

## 📋 Справочники

Справочники доступны из меню **«Справочники»** (для менеджеров и администраторов).
Каждый справочник поддерживает добавление, редактирование и удаление записей.

### Цеха

Цеха предприятия (например, «Сборочный цех», «Литейный цех»). Значение
используется в карточке работника и в аналитике по цехам.

### Разряды

Тарифные разряды работников (1–6 и выше). Разряд указывается в карточке работника.

### Системы оплаты

| Система | Описание |
|---------|----------|
| **Оклад** | Фиксированная зарплата в месяц |
| **Почасовая** | Оплата по ставке за фактически отработанные часы |
| **Сдельная** | Оплата за объём выполненной работы |
| **Проектная** | Оплата за участие в проекте |

### Категории работников

Категории персонала (например, «Рабочий», «Специалист»).

### Режимы работы

Режимы труда (например, «Односменный», «Двухсменный», «Трёхсменный»,
«Гибкий график»).

### Оклады и почасовые ставки

Заранее заданные значения окладов (руб/мес) и почасовых ставок (руб/час),
используемые при оформлении работников.

### Тарифы

Справочник тарифов для расчёта сдельной/проектной оплаты.

## ⏰ Учёт рабочего времени

Раздел показывает по месяцам для работника:

- **Часы по плану** и **по факту**;
- **Дни отработано**;
- **Больничные дни** и **командировочные дни**.

Для изменения записи нажмите кнопку редактирования и укажите новые значения.
Данные учёта времени используются при расчёте заработной платы.

## 💰 Зарплата

### Просмотр зарплаты

Страница зарплаты работника показывает:

- систему оплаты и ставку/оклад;
- сумму к начислению за выбранный месяц;
- отдельно начисленные больничные и командировочные.

### История зарплаты

Таблица начислений по месяцам (год, месяц, общая зарплата, больничные,
командировочные). Позволяет отслеживать динамику выплат работника.

### Системы оплаты труда

Расчёт выполняется по одной из четырёх систем (см. [Справочники → Системы оплаты](#системы-оплаты)).
Сводный отчёт по всем работникам за период доступен через
[PDF-отчёт по зарплате](#pdf-отчёты).

## 📊 Дашборд и аналитика

Дашборд (`/dashboard`) предоставляет аналитику в реальном времени:

- общее количество работников и цехов;
- средняя зарплата и общий фонд оплаты труда;
- распределение работников по цехам и категориям;
- распределение зарплат.

Данные обновляются автоматически (polling каждые 5–10 секунд).

## 🏢 Организации и тарифные планы

### Мульти-тенантность

Система поддерживает несколько организаций в одной инсталляции. Каждый работник
принадлежит своей организации, и пользователи видят только данные своей
организации (если у них нет глобальной роли `admin`).

Раздел **«Организации»** (только для администраторов) позволяет:
- создавать и деактивировать организации;
- просматривать организации и их пользователей;
- назначать роли пользователям внутри организации;
- управлять тарифным планом организации.

### Тарифные планы

| План | Лимит работников | Лимит организаций |
|------|------------------|-------------------|
| **Бесплатный** (Free) | 10 | 1 |
| **Pro** | 50 | 3 |
| **Enterprise** | без ограничений | без ограничений |

При превышении лимита работников добавление нового работника блокируется.

### Пользователи организации

Администратор организации (`org_admin`) управляет пользователями и их ролями
в пределах своей организации на странице организации.

## 📤 Отчёты и экспорт данных

> **Примечание.** Экспорт выполняется через REST API по прямым ссылкам.
> Браузер сохранит скачанный файл после авторизации в системе.

### PDF-отчёты

| Эндпоинт | Описание |
|----------|----------|
| `GET /api/reports/worker/:id/pdf` | Отчёт по работнику: сведения, история зарплаты, учёт времени |
| `GET /api/reports/workers/pdf` | Список работников с деталями |
| `GET /api/reports/salary/pdf?year=YYYY&month=M` | Отчёт по зарплате за период (с итоговой строкой) |

Пример:

```bash
curl -b cookies.txt "http://localhost:3000/api/reports/salary/pdf?year=2025&month=10" -o salary_2025_10.pdf
```

Если параметры `year`/`month` не указаны, используется текущий период.
Некорректные параметры (например, месяц 13) возвращают ошибку.
Кириллица в PDF поддерживается (шрифт DejaVu Sans; можно задать путь через
переменную окружения `PDF_FONT`).

### Экспорт в CSV и Excel

| Эндпоинт | Формат | Содержимое |
|----------|--------|------------|
| `GET /api/export/workers.csv` | CSV | Список работников |
| `GET /api/export/salary.csv` | CSV | Зарплатные данные |
| `GET /api/export/workers.xlsx` | Excel | Список работников |

### Интеграция с 1С

Эндпоинты интеграции с 1С:ЗУП (только для администраторов):

| Эндпоинт | Описание |
|----------|----------|
| `GET /api/1c/workers?format=xml` | Выгрузка работников в XML |
| `GET /api/1c/salary?format=xml&year=YYYY&month=M` | Выгрузка зарплаты в XML |
| `POST /api/1c/workers/import` | Импорт работников из 1С |
| `GET /api/1c/docs` | Документация по интеграции |

## 🛡️ Мониторинг и безопасность

### Health Check и метрики

| Эндпоинт | Описание |
|----------|----------|
| `GET /api/health` | Статус БД и приложения (публичный) |
| `GET /api/ready` | Готовность к работе |
| `GET /api/live` | Живость процесса |
| `GET /api/metrics` | Метрики в формате Prometheus |
| `GET /api/stats` | Статистика приложения |

### Аудит и сессии

- **Аудит изменений** (`/api/audit*`, только admin) — журнал операций с данными.
- **Аудит сессий** (`/api/sessions*`) — входы, выходы, неудачные попытки,
  активные сессии, статистика.

### Ограничения доступа

- Доступ к функциям проверяется на уровне маршрутов по роли пользователя;
- Страница «Все таблицы» (`/db`) доступна только администраторам;
- API ограничен по частоте запросов (rate limiting): API — 30 запросов/мин на IP,
  страницы — 100/мин.

## ❓ Вопросы и ответы (FAQ)

**Как войти в систему?**
Откройте `/login` и введите имя пользователя и пароль, выданные администратором.
В демо-окружении используется пользователь `admin` (пароль задан в файле `.env`).

**Почему не работает кнопка добавления работника?**
Проверьте, что у вашей роли есть права на запись (`manager`, `hr`, `admin`
или соответствующая роль организации). Наблюдатели могут только просматривать.

**Где скачать отчёт по зарплате?**
Перейдите по ссылке `GET /api/reports/salary/pdf?year=YYYY&month=M`
(требуется авторизация в системе).

**Почему PDF не отображает кириллицу?**
Убедитесь, что на сервере установлен шрифт с поддержкой кириллицы (например,
DejaVu Sans) или укажите путь к шрифту через переменную окружения `PDF_FONT`.

**Что делать, если система блокирует вход?**
После нескольких неудачных попыток входа IP блокируется на время.
Подождите несколько минут или обратитесь к администратору.

**Email-уведомления не приходят — почему?**
Функциональность email-уведомлений в текущей версии отключена (заглушка).
Страница уведомлений и эндпоинты API возвращают статус «функциональность отключена».
