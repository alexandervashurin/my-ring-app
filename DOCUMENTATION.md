## Обзор проекта

**Система управления персоналом** — веб-приложение для автоматизации кадрового учёта на производственном предприятии (завод по производству автоматических коробок передач).

### Назначение
- Управление базой данных работников (CRUD-операции)
- Учёт рабочего времени (отработанные часы, больничные, командировки)
- Расчёт заработной платы (окладная, почасовая, сдельная, проектная системы)
- Аналитика и отчётность (дашборд с метриками)
- Просмотр всех таблиц базы данных

### Целевая аудитория
- Отделы кадров промышленных предприятий
- Бухгалтерии для расчёта зарплаты
- Руководители цехов и подразделений
- Специалисты по учёту рабочего времени

## Архитектура приложения

Приложение построено по архитектуре **MVC (Model-View-Controller)** с использованием функционального подхода Clojure.

```
┌─────────────────────────────────────────────────────────┐
│                    HTTP Request                         │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│              Middleware Stack (core.clj)                │
│  • Security Headers • Error Handler • Content-Type      │
│  • File Info • Keyword Params • Params • JSON           │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│              Routes (routes.clj)                        │
│  Compojure маршрутизация запросов                       │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│           Controllers (controllers.clj)                 │
│  Обработка запросов, валидация, подготовка данных       │
└─────────────────────────────────────────────────────────┘
                           │
              ┌────────────┴────────────┐
              │                         │
              ▼                         ▼
┌─────────────────────────┐   ┌─────────────────────────┐
│    Model (model.clj)    │   │  Views (views/*.clj)    │
│  Работа с БД (JDBC)     │   │  Генерация HTML         │
└─────────────────────────┘   └─────────────────────────┘
              │                         │
              ▼                         │
┌─────────────────────────┐             │
│   SQLite Database       │             │
│   (igra.db)             │             │
└─────────────────────────┘             │
                                        │
                                        ▼
                              ┌─────────────────────────┐
                              │    HTTP Response        │
                              │    (HTML/JSON)          │
                              └─────────────────────────┘
```

### Компоненты архитектуры

| Компонент | Файл | Описание |
|-----------|------|----------|
| **Точка входа** | `core.clj` | Запуск сервера, middleware цепочка |

| **Конфигурация** | `config.clj` | Настройки подключения к БД, порту |

- `-main` — Точка входа приложения

**Middleware цепочка (снаружи внутрь):**
```clojure
app-routes
  → wrap-security-headers
    → wrap-error-handler
      → wrap-content-type
        → wrap-file-info
          → wrap-keyword-params
            → wrap-params
              → wrap-json-body
                → wrap-json-response
```

#### validation.clj (Валидация)

**Функции:**

| Функция | Параметры | Проверки |
|---------|-----------|----------|
| `validate-worker` | data | Фамилия, имя, отчество, дата приёма, цех, система оплаты, категория, разряд, режим, оклад/ставка |
| `validate-work-time` | data | Год, месяц, плановые часы, фактические часы, отработанные дни, рабочие часы, больничные, командировочные |

**Правила валидации работника:**
- Фамилия: обязательна, макс. 50 символов
- Имя: обязательно, макс. 50 символов
- Отчество: необязательно, макс. 50 символов
- Дата приёма: обязательна, формат ГГГГ-ММ-ДД, не в будущем
- Цех: обязательный выбор из справочника
- Система оплаты: обязательный выбор
- Категория работника: обязательный выбор
- Разряд: обязательный выбор
- Режим работы: обязательный выбор
- Оклад: обязателен для окладной системы
- Почасовая ставка: обязательна для почасовой системы

## База данных

### Схема БД (10 таблиц)

#### Основные таблицы

**Работник** (главная таблица)
```sql
CREATE TABLE Работник (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    фамилия TEXT NOT NULL,
    имя TEXT NOT NULL,
    отчество TEXT,
    дата_приема DATE NOT NULL,
    цех_id INTEGER NOT NULL,
    система_оплаты_id INTEGER NOT NULL,
    категория_работника_id INTEGER NOT NULL,
    разряд_id INTEGER NOT NULL,
    режим_работы_id INTEGER NOT NULL,
    оклад_id INTEGER,              -- NULL для почасовой оплаты
    почасовая_ставка_id INTEGER    -- NULL для окладной оплаты
);
```

**Учет_рабочего_времени**
```sql
CREATE TABLE Учет_рабочего_времени (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    работник_id INTEGER NOT NULL,
    год INTEGER NOT NULL,
    месяц INTEGER NOT NULL,
    всего_часов_за_месяц_по_плану INTEGER NOT NULL,
    всего_часов_в_месяц_по_факту INTEGER NOT NULL,
    количество_отработанных_дней INTEGER,
    количество_рабочих_часов_в_день INTEGER,
    всего_отработанных_часов INTEGER,
    сколько_должны_отработать INTEGER,
    больничные_дни INTEGER DEFAULT 0,
    командировочные_дни INTEGER DEFAULT 0
);
```

**Начисление_заработной_платы**
```sql
CREATE TABLE Начисление_заработной_платы (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    учет_рабочего_времени_id INTEGER NOT NULL,
    год INTEGER NOT NULL,
    месяц INTEGER NOT NULL,
    зарплата_за_больничные_дни DECIMAL(10,2) DEFAULT 0,
    зарплата_за_командировочные_дни DECIMAL(10,2) DEFAULT 0,
    общая_зарплата DECIMAL(10,2) NOT NULL
);
```

#### Справочные таблицы

| Таблица | Поля | Записей (примерно) |
|---------|------|-------------------|
| **Цех** | id, название_цеха | 20+ (10 основных + подрядчики) |
| **Система_оплаты** | id, название_системы | 7 (Оклад, Почасовая, Сдельная, Смешанная, ...) |
| **Категория_работника** | id, название_категории | 8 (Рабочий, Специалист, Руководитель, Служащий, Стажёр, ...) |
| **Разряд** | id, номер_разряда | 8 (1-8 разряды) |
| **Режим_работы** | id, название_режима | 9 (Односменный, Двухсменный, Вахтовый, ...) |
| **Оклад** | id, оклад_в_месяц | 20+ (25000 - 200000 ₽) |
| **Почасовые_ставки** | id, ставка_в_час | 14+ (150 - 600 ₽/час) |

### Связи между таблицами

```
Работник
  ├──→ Цех (many-to-one)
  ├──→ Система_оплаты (many-to-one)
  ├──→ Категория_работника (many-to-one)
  ├──→ Разряд (many-to-one)
  ├──→ Режим_работы (many-to-one)
  ├──→ Оклад (many-to-one, nullable)
  └──→ Почасовые_ставки (many-to-one, nullable)

Учет_рабочего_времени
  └──→ Работник (many-to-one)

Начисление_заработной_платы
  └──→ Учет_рабочего_времени (one-to-one)
```

**Ответ:** HTML страница

```bash
curl http://localhost:3000/
```

#### GET /dashboard — Дашборд

**Описание:** Аналитическая панель с метриками

**Данные:**
- Общая статистика (кол-во работников, цехов, средняя зарплата, фонд оплаты)
- Распределение по цехам
- Распределение по категориям
- Распределение по разрядам

- Статистика посещаемости

**Ответ:** HTML страница с графиками и таблицами

**Примеры:**
```bash
# Все работники
curl http://localhost:3000/workers

# Поиск по фамилии
curl http://localhost:3000/workers?search=Иванов

# Поиск по цеху
curl http://localhost:3000/workers?search=Литейный
```

## Безопасность

### Реализованные механизмы защиты

| Механизм | Заголовок/Мера | Значение |
|----------|----------------|----------|
| **XSS-защита** | HTML-экранирование | Все пользовательские данные экранируются (`&`, `<`, `>`, `"`, `'`) |
| **CSRF-защита** | Middleware | Защита от CSRF-атак на формах |
| **Clickjacking** | X-Frame-Options | DENY |
| **MIME-sniffing** | X-Content-Type-Options | nosniff |
| **XSS-фильтр** | X-XSS-Protection | 1; mode=block |
| **CSP** | Content-Security-Policy | default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' |
| **SRI** | Subresource Integrity | Проверка целостности статических ресурсов |
| **Secure Cookie** | Cookie флаг | Secure для сессионных cookies |
| **Session Revalidation** | Проверка при запросе | Проверка активности пользователя (is_active=1) |
| **Brute-force Protection** | Rate Limiting | 5 неудачных попыток → 15 минут блокировки |

| **Input Validation** | Валидация | Email, year/month, ID на всех endpoint'ах |

### Функция `wrap-security-headers`

```clojure
(defn wrap-security-headers [handler]
  (fn [request]
    (let [response (handler request)]
      (-> response
          (assoc-in [:headers "X-Frame-Options"] "DENY")
          (assoc-in [:headers "X-Content-Type-Options"] "nosniff")
          (assoc-in [:headers "X-XSS-Protection"] "1; mode=block")
          (assoc-in [:headers "Content-Security-Policy"] 
                    "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'")))))
```

### Функция `html-escape`

```clojure
(defn html-escape [s]
  (if (nil? s)
    ""
    (-> (str s)
        (str/replace "&" "&amp;")
        (str/replace "<" "&lt;")
        (str/replace ">" "&gt;")
        (str/replace "\"" "&quot;")
        (str/replace "'" "&#x27;"))))
```

## Приложения

### A. Примеры SQL-запросов

**Получение работника с деталями:**
```sql
SELECT r.id, r.фамилия, r.имя, r.отчество, r.дата_приема,
       ц.название_цеха as цех,
       с.название_системы as система,
       к.название_категории as категория,
       рз.номер_разряда as разряд,
       рм.название_режима as режим
FROM Работник r
LEFT JOIN Цех ц ON r.цех_id = ц.id
LEFT JOIN Система_оплаты с ON r.система_оплаты_id = с.id
LEFT JOIN Категория_работника к ON r.категория_работника_id = к.id
LEFT JOIN Разряд рз ON r.разряд_id = рз.id
LEFT JOIN Режим_работы рм ON r.режим_работы_id = рм.id
WHERE r.id = 1;
```

**Расчёт зарплаты:**
```sql
SELECT r.фамилия, r.имя,
       CASE
           WHEN r.система_оплаты_id = 1 THEN о.оклад_в_месяц
           WHEN r.система_оплаты_id = 2 THEN п.ставка_в_час * у.всего_отработанных_часов
       END as зарплата
FROM Работник r
LEFT JOIN Учет_рабочего_времени у ON r.id = у.работник_id
LEFT JOIN Оклад о ON r.оклад_id = о.id
LEFT JOIN Почасовые_ставки п ON r.почасовая_ставка_id = п.id
WHERE у.год = 2025 AND у.месяц = 10;
```
